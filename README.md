# BLACKLINES — Barber Studio

**Una experiencia web moderna para una barbería ficticia, diseñada para combinar identidad visual, funcionalidad y una navegación intuitiva.**

[🌐 Ver demostración](https://myrem-droid.github.io/Blackline-barber-a/)

---

## ✦ Descripción

BLACKLINES es un proyecto de desarrollo web creado para demostrar cómo una barbería puede presentar sus servicios y construir una presencia digital profesional.

El proyecto utiliza una estética oscura con detalles dorados, una interfaz responsive y componentes interactivos desarrollados con tecnologías web fundamentales.

## ✦ Características

- Diseño moderno con identidad visual propia.
- Interfaz adaptable a dispositivos móviles, tablets y escritorio.
- Sección de servicios y precios.
- Galería visual.
- Formulario de reservas demostrativo.
- Panel administrativo de demostración.
- Interacciones mediante JavaScript.
- Animaciones y transiciones.
- Optimización SEO básica.

## ✦ Tecnologías

| Tecnología | Uso |
